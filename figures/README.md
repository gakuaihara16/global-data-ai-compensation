# Project figures

These nine high-resolution charts were extracted **without redrawing** from the team's October 2026 presentation, preserving the original plot labels, values, colors, and captions. They are presented separately from the final slide deck, which will be added after revisions.

**Source:** Team Libeccio (Gaku Aihara, Emily Wang, Snehil Rayal), *Global Data & AI Workforce Compensation Analytics* (2026), using the aijobs.net salary snapshot dated August 3, 2025.

> **Note:** Figures describe cross-sectional salary records rather than verified individuals or individual raises. Reported salaries are nominal annual base amounts, not total compensation or cost-of-living-adjusted values. Chart images are not a substitute for the code and methodological caveats in [`analysis.qmd`](../analysis.qmd).
